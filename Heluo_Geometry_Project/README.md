# 河洛几何验证项目

## 简介
本项目基于 PDG 粒子物理数据，验证河洛几何的核心预言：粒子质量谱存在 2^(k/5) 离散结构，三种规范力来自五维几何的投影，引力可嵌入同一几何框架。

## 项目结构
Heluo_Geometry_Project/
├── data/ # 实验数据
├── core/ # 公理与核心模块
├── models/ # 各版本模型
├── utils/ # 工具函数
├── main.py # 主入口
├── requirements.txt # 依赖
└── README.md # 本文件
